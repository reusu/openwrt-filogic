# Tenda BE12 Pro

## Hardware

- SoC: MediaTek MT7987A (quad-core ARM Cortex-A53 @ 2.0 GHz)
- RAM: 512 MiB DDR4
- Flash: 128 MiB SPI-NAND
- WiFi: MediaTek MT7992E (WiFi 7, 2.4G 4x4 + 5G 4x4)
- Ethernet:
  - 3x 1G LAN (Airoha AN8855AE switch → `lan3` `lan4` `lan5`)
  - 1x 2.5G LAN (SoC internal 2.5G PHY → `eth1`)
  - 1x 2.5G WAN (Airoha EN8811H PHY → `eth2`)
- Buttons: Reset, WPS
- LEDs: blue status / red alarm
- UART: 115200 8n1 (VCC, RX, TX, GND)

MAC addresses (`Factory` partition, base at offset `0x4`):

| Interface | Offset |
|---|---|
| label-mac / gmac0 (2.5G LAN CPU) | base - 2 |
| gmac2 (WAN `eth2`) | base - 1 |
| gmac1 (2.5G LAN `eth1`) | base - 2 |
| 2.4 GHz radio | base + 1 |
| 5 GHz radio | base + 3 |

## Installation

1. Open the case and connect UART (115200 8n1).
2. Interrupt U-Boot with `Ctrl+C` during boot.
3. Copy the generated Tenda initramfs image to a TFTP server at 192.168.1.2
   under the filename `openwrt-initramfs.bin`, then:
   ```
   tftpboot openwrt-initramfs.bin
   bootm
   ```
4. Once booted into the OpenWrt initramfs, flash the sysupgrade image via LuCI/SSH:
   ```
   sysupgrade -n /tmp/openwrt-mediatek-filogic-tenda_be12-pro-squashfs-sysupgrade.bin
   ```

The stock bootloader requires a 16-byte `God1` dual-image header, generated by the `tenda-mkdualimageheader` image command included in the overlay.

Imported from the Tenda overlay with its original upstream authorship retained.
The shared workflow builds this target alongside TE-42, TE-43 and E87N.
Its NAND partitions and God1 image wrapper remain separate from the Hiveton eMMC upgrade paths.

## Compatibility with 25.12.6

The imported board DTS matches the upstream Tenda file. The local overlay adds
`#address-cells = <1>` and `#size-cells = <0>` to `&spi0` because the MT7987
base DTS shipped in v25.12.6 omits them. Upstream `main` already provides both
properties in `mt7987.dtsi`; this is a compatibility adjustment for the older
base, not an upstream SPI driver or hardware fix. It leaves the chip select,
52 MHz clock limit, quad-data mode and NAND partitions unchanged.
